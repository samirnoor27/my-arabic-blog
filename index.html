دليل النشر المجاني بضغطة زر واحدة (Deploy Guide)

تعليمات رفع الموقع على GitHub Pages و Netlify وسكريبت التشغيل

1. النشر عبر GitHub Pages

  1. قم بإنشاء مستودع جديد (Repository) على حسابك في GitHub.
  2. قم برفع هذا الملف وتسميته باسم index.html.
  3. اذهب إلى إعدادات المستودع Settings -> Pages.
  4. اختر الفرع main / master ثم اضغط Save.
  5. سيكون موقعك متوفراً خلال ثوانٍ على رابط مجاني مثل: username.github.io/repo.

2. النشر الفوري عبر Netlify Drop

  1. افتح موقع Netlify Drop.
  2. ضع ملف index.html في مجلد فارغ.
  3. اسحب المجلد وأفْلِتْه في مربع Netlify.
  4. سيتم نشر الموقع فوراً بضغطة زر مع شهادة أمان SSL مجانية!

أوامر السكريبت للرفع بضغطة زر (Terminal Script):

# سكريبت النشر المباشر عبر Git
git init
git add .
git commit -m "الإصدار الأول من المدونة العربية"
git branch -M main
git remote add origin https://github.com/USERNAME/arabic-blog.git
git push -u origin main
